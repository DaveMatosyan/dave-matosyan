# davidmatosyan.dev

Personal site for David Matosyan — backend engineer × AI-native builder.

Built the way David works: directed by David, written by Claude, reviewed line by line.

## Stack

Next.js (App Router) · Tailwind v4 · `motion` + `lenis` · fully static.

All site copy lives in [`lib/content.ts`](lib/content.ts) — edit words there, never in markup.

## Develop

```bash
npm run dev
```

## Deploy

```bash
vercel --prod
```
